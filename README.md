# Public

A home for small, browser-ready HTML and JavaScript pages.

## Run locally

Open an HTML file directly in a browser, or serve this folder with any static file server. For example:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000/`.

## Pages

Add standalone pages as HTML files in the repository root, or give each page its own folder. Keep browser assets (CSS, JavaScript, images) alongside the page that uses them.

## GitHub Pages

This repository is structured as a static site. After publishing, enable GitHub Pages in the repository settings and select the `main` branch and `/ (root)` as the source. Pages will then be available at the site's GitHub Pages address, including direct links to individual HTML files.
